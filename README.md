# আমিনপুর ম্যাপ — Aminpur Map

বাংলাদেশের পাবনা জেলার নবগঠিত **আমিনপুর থানা** এবং এর আওতাধীন ৮টি ইউনিয়ন ও আশপাশের এলাকার জন্য একটি আধুনিক, নির্ভুল, দ্রুতগতির, সম্পূর্ণ বাংলাভিত্তিক ডিজিটাল ম্যাপ ও প্রগ্রেসিভ ওয়েব অ্যাপ (PWA)।

---

## ১. প্রকল্পের মূল বৈশিষ্ট্যসমূহ

- **সম্পূর্ণ বাংলা ইন্টারফেস**: টাইপোগ্রাফিতে *SolaimanLipi* (সোলাইমান লিপি) এবং ব্যাকআপ হিসেবে *Noto Sans Bengali* ফন্ট ব্যবহৃত।
- **বাস্তব ভৌগোলিক ও OpenStreetMap ডেটা**:
  - প্রধান মহাসড়ক (R540 কাশীনাথপুর–আমিনপুর–কাজিরহাট, N5 অংশ), গ্রামীণ পাকা রাস্তা, কাঁচা রাস্তা ও বাঁধ সড়ক।
  - গুরুত্বপূর্ণ নদী ও নৌপথ (পদ্মা ও যমুনা নদী মিলনস্থল, বাদাই নদী, সুতিখালি খাল, কাজিরহাট–পাটুরিয়া ফেরিপথ)।
  - ৮টি ইউনিয়নের প্রশাসনিক কেন্দ্র ও সীমানা (জাতসাকিনী, মাসুন্দিয়া, রূপপুর, ঢালচর, পুরান ভারেঙ্গা, সাগরকান্দি, রানীনগর, আহমেদপুর)।
  - ঐতিহাসিক ও গুরুত্বপূর্ণ স্থান (আমিনপুর থানা, কাজিরহাট ফেরি ও লঞ্চ ঘাট, ঐতিহাসিক নগরবাড়ী বন্দর, স্কুল, কলেজ, মাদ্রাসা, হাট-বাজার, হাসপাতাল ও ধর্মীয় উপাসনালয়)।
- **প্রকৃত অফলাইন সক্ষমতা (True Offline Capability)**:
  - IndexedDB-তে সংরক্ষিত অফলাইন ভেক্টর কোর প্যাক।
  - ইন্টারনেট ছাড়াই রাস্তা, গ্রাম, ল্যান্ডমার্ক ও ইউনিয়ন সীমানা প্রদর্শন।
  - অফলাইন রাউটিং ইঞ্জিন — ইন্টারনেট ছাড়াই মোড় ঘোরার টার্ন-বাই-টার্ন বাংলা নির্দেশনা।
- **লাইভ GPS ও বর্তমান অবস্থান**:
  - ব্রাউজার Geolocation API দিয়ে ব্যবহারকারীর সঠিক অবস্থান ও নির্ভুলতার ব্যাসার্ধ (Accuracy circle) প্রদর্শন।
- **উন্নত বাংলা অনুসন্ধান ইঞ্জিন**:
  - বাংলা ইউনিকোড নর্মালাইজেশন, অতিরিক্ত স্পেস ও যতিচিহ্ন দূরীকরণ এবং ইংরেজি লিপ্যন্তর সার্চ সমর্থন।
- **PWA এবং ইনস্টলেশন**:
  - Android ও iOS-এ হোম স্ক্রিনে নেটিভ অ্যাপের মতো ইনস্টলযোগ্য।
  - Service Worker ও Web App Manifest কনফিগারেশন।
- **আধুনিক ও দৃষ্টিনন্দন UI/UX**:
  - হালকা (Light) ও ডার্ক (Dark) থিম।
  - বাংলা সংখ্যা পদ্ধতি (১২৩৪) বা আন্তর্জাতিক সংখ্যা পদ্ধতির টগল।
  - মোবাইলে এক হাতে ব্যবহারের উপযোগী নিচের নেভিগেশন বার (Bottom Navigation)।

## ২. ব্যবহৃত প্রযুক্তি কাঠামো

- **Frontend**: React 19, TypeScript
- **Bundler & Tooling**: Vite, @vitejs/plugin-react, vite-plugin-pwa
- **Styling**: Tailwind CSS
- **Map & GIS**: Leaflet, GeoJSON, OpenStreetMap, Esri World Imagery (স্যাটেলাইট স্তর), OpenTopoMap (ভূপ্রকৃতি স্তর)
- **Local Storage**: IndexedDB (ব্রাউজার নেটিভ ডেটাবেস)
- **Icons**: Lucide React

## ৪. লোকাল কম্পিউটারে রান করার নিয়ম

প্রকল্পটি আপনার কম্পিউটারে চালাতে নিচের ধাপগুলো অনুসরণ করুন:

১. রিপোজিটরিটি ক্লোন করুন অথবা ডাউনলোড করুন:
```bash
git clone https://github.com/YOUR_USERNAME/aminpur-map.git
cd aminpur-map
```

২. প্রয়োজনীয় ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

৪. ব্রাউজারে `http://localhost:3000` অথবা কনসোলে দেখানো লোকাল পোর্টে যান।

৫. প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```

## ৫. আমিনপুরের ম্যাপ ডেটা প্রস্তুত ও আপডেট পদ্ধতি

আমিনপুর থানার ম্যাপ ডেটা প্রধানত **OpenStreetMap (OSM)** থেকে সংগৃহীত। আপনি যদি ভবিষ্যতে আরও রাস্তা বা স্থানের ডেটা আপডেট করতে চান:

১. **Overpass API কোয়েরি**:
   আমিনপুর এলাকার বাউন্ডিং বক্স (`[bbox:23.90,89.50,24.06,89.75]`) ব্যবহার করে ওভারপাস টার্বো (`https://overpass-turbo.eu`) থেকে নতুন ডেটা নামাতে পারেন:
   ```overpass
   [out:json][timeout:25];
   (
     node["amenity"](23.90,89.50,24.06,89.75);
     way["highway"](23.90,89.50,24.06,89.75);
     relation["boundary"="administrative"](23.90,89.50,24.06,89.75);
   );
   out body;
   >;
   out skel qt;
   ```

২. **অ্যাপের নিজস্ব ডেটা কন্ট্রিবিউশন ফর্ম**:
   - অ্যাপের ওপরের ডান কোণে `+ স্থান যোগ` বাটনে ক্লিক করে যেকোনো নতুন স্থান সরাসরি যুক্ত করা যাবে।
   - সেখান থেকে একক স্থান বা সংশোধিত তথ্য সরাসরি `JSON` ফাইল হিসেবে এক্সপোর্ট করে নেওয়া যায়।
   - এই JSON তথ্য পরবর্তীতে `src/data/placesData.ts` ফাইলে যুক্ত করলেই অ্যাপের সাথে স্বয়ংক্রিয়ভাবে মার্জ হয়ে যাবে।

## ৬. অফলাইন ম্যাপ প্যাক তৈরির ও ব্যবহারের নির্দেশনা

- সাধারণ টাইল সার্ভার থেকে লাখ লাখ টাইল স্ক্র্যাপ করা OpenStreetMap টাইল ইউসেজ পলিসির পরিপন্থী। তাই এই অ্যাপে **ভেক্টর ডেটা ও রোড গ্রাফ ভিত্তিক প্রকৃত অফলাইন প্রযুক্তি** ব্যবহার করা হয়েছে।
- অ্যাপের **অফলাইন** ট্যাবে গিয়ে "অফলাইন ম্যাপ ডাউনলোড করুন" বাটনে ট্যাপ করলে সমগ্র আমিনপুর এলাকার রাস্তা, নদী, ঘাট, স্কুল ও বাজারের কোঅর্ডিনেট ব্রাউজারের **IndexedDB**-তে সংরক্ষিত হয়।
- ডাউনলোড সম্পন্ন হলে "অফলাইন ম্যাপ ব্যবহারের জন্য প্রস্তুত" বার্তা আসবে।
- এর পর ডিভাইস ফ্লাইট মোডে বা ডাটা সংযোগ বন্ধ রাখলেও মানচিত্রে সমস্ত রাস্তা ও ল্যান্ডমার্ক নিখুঁতভাবে দেখা যাবে এবং রুট নির্ধারণ করা যাবে।

## ৮. Vercel-এ ডেপলয় করার ধাপ

১. [Vercel](https://vercel.com)-এ লগইন করে **Add New... > Project** নির্বাচন করুন।
২. আপনার GitHub রিপোজিটরি `aminpur-map` সিলেক্ট করুন।
৩. সেটিংস যাচাই করুন:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
৪. **Deploy** বাটনে ক্লিক করুন। ২ মিনিটের মধ্যে আপনার লাইভ সাইট তৈরি হয়ে যাবে!
*(প্রকল্পটিতে আগেই `vercel.json` কনফিগার করে দেওয়া আছে, ফলে SPA রাউটিং স্বয়ংক্রিয়ভাবে কাজ করবে।)*

## ৯. অফলাইন ম্যাপ পরীক্ষার নির্দেশনা

১. ব্রাউজারে অ্যাপটি চালু করুন এবং **অফলাইন** ট্যাবে গিয়ে অফলাইন প্যাক ডাউনলোড সম্পন্ন করুন।
২. এবার মোবাইল বা ল্যাপটপের **WiFi / Mobile Data বন্ধ করুন** অথবা ব্রাউজার DevTools-এর Network ট্যাবে গিয়ে **Offline** সিলেক্ট করুন।
৩. পেজ রিফ্রেশ করুন। লক্ষ্য করবেন অ্যাপটি তাৎক্ষণিকভাবে সার্ভিস ওয়ার্কারের মাধ্যমে চালু হচ্ছে।
৪. ম্যাপ স্ক্রিনে যান এবং যেকোনো বাজার বা স্কুলে ট্যাপ করে "রুট দেখুন" বাটনে ক্লিক করুন। অফলাইন রোড গ্রাফ স্বয়ংক্রিয়ভাবে টার্ন-বাই-টার্ন পথ হিসাব করবে।

## ১০. পরিচিত সীমাবদ্ধতা ও পরবর্তী উন্নয়ন পরিকল্পনা

- **সীমাবদ্ধতা**:
  - পাবনার চরাঞ্চলের কিছু কাঁচা মেঠোপথ মৌসুমি বন্যার কারণে বর্ষায় স্থান পরিবর্তন হতে পারে।
  - ওপেনস্ট্রিটম্যাপে কিছু গ্রামীণ দোকানের নাম এখনো নথিভুক্ত করা হয়নি।
- **ভবিষ্যৎ উন্নয়ন**:
  - মৌসুমি বন্যা বা ভাঙা সড়কের লাইভ রিপোর্ট দেওয়ার ব্যবস্থা।
  - কাজিরহাট–পাটুরিয়া ফেরি চলাচলের লাইভ সময়সূচি যোগ করা।
  - আমিনপুর বাজার ও কাশিনাথপুর মোড়ের স্থানীয় বাস রুটের ডিজিটাল শিডিউল।
